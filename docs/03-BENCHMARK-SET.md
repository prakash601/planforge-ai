# Benchmark set (you build it yourself)

Composition is specified so it cannot be flattered:

- One multi-room capture: 3+ rooms plus a connector
- One furnished room with staged damage spanning 2 damage classes
- Same rooms captured at ALL THREE input tiers, multi-room set included: at photo tier it arrives as per-room photo folders and must still stitch
- At least one room captured twice at the same tier (repeatability gate)
- Laser or tape ground truth on everything
- Raw sensor data + measurements submitted

Covers mirrors, glass, wet-look surfaces and low light in the submission (per Constraints).
